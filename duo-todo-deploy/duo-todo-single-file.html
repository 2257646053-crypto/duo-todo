使用帮助

1. 装到手机桌面（两台 Android）

用 Chrome 打开本页链接 → 如果顶部出现「装到手机桌面」提示条，直接点「添加」即可；没出现就点 Chrome 右上角 ⋮ → 安装应用 或 添加到主屏幕。

从桌面图标打开是全屏的，没有地址栏。多数启动器会在图标上显示未完成数量的角标。

2. 两台手机怎么配对

① 各自打开应用，选择「这台手机是谁」，两人选不同的人。
② 不配置云也能用：各自记各自的，用提醒按钮把事发到微信。
③ 想实时同步：按设置页「第一次用？点开看建表步骤」做一次，约 3 分钟，全程免费。两人房间码一致即可。

3. 微信里互相提醒

每条待办右边的纸飞机按钮 → 自动生成一段提醒文字 → 弹出系统分享面板 → 选 微信 → 选对方发送。若浏览器不支持分享，文字会自动复制，打开微信粘贴即可。

微信没有开放「自动给个人发消息」的接口，所以这一步需要你点一下，好处是零配置、不受条数限制、不会被风控。

4. 板块与权限

三个板块都有自己的添加框：我的 / 我们 / TA 的。对方板块可以帮 TA 记一条，但只有 TA 本人能勾选完成。共同区两人都能添加和勾选。

紧急程度分「普通 / 重要 / 紧急」，列表自动按紧急优先、再按截止时间排，已完成自动沉底。

5. 隐私与可靠性

所有待办默认只存在本机浏览器存储里，不上传。开启云同步后，数据存放在你自己注册的 Supabase 项目里，靠一长串随机房间码区分；链接和配置别外传。

免费云有休眠机制，但本地始终有一份完整数据，云断了应用照常用。建议偶尔用「导出备份」存一份文件。
